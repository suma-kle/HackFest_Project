Space Debris Detection, Collision Risk and Manoeuvre Advisor

About the Project:

This project is developed by our team for HackFest 2026. It aims to identify space debris, assess potential collision risks, and help recommend safe manoeuvres for spacecraft.

Problem Statement:

Space debris orbiting Earth can threaten satellites and spacecraft. Collisions with debris can damage important space infrastructure and interrupt satellite services. Therefore, detecting debris and assessing collision risks are important for improving space safety.

Proposed Solution:

We aim to develop a system that analyses space debris data, identifies potential collision risks, and provides suitable manoeuvre recommendations to help spacecraft avoid possible collisions.
